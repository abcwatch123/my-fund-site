Time-weighted return

Time-weighted return measures investment performance after adjusting for deposits and withdrawals. It compounds the returns of successive subperiods to remove the effect of the size and timing of external cash flows.

Compound annual return

Compound annual return is the constant annual rate that would produce the cumulative return since inception when compounded over the same period. It is a geometric annualised return, rather than a simple average of yearly returns.

Cumulative return

Cumulative return is the total compounded return since inception. Each point shows the total gain or loss from inception to the stated year-end, rather than the return for that period alone.
